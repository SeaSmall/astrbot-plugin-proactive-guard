# AstrBot 主动消息门禁 + 每日定时人格消息（proactive_guard）

一个 [AstrBot](https://github.com/AstrBotDevs/AstrBot)（4.x）插件，做两件事：

1. **🚪 主动消息门禁**：阻止「本插件之外」的 AI 主动发言。只要用户没有发消息，任何 AI 对话的**生成与发送都会被拦截**——包括 AstrBot 内置「主动型 Agent」、定时主动任务、陪伴类插件等。用户正常发消息聊天完全不受影响。
2. **💬 每日定时人格消息**：每天 **06:00** 在**后台静默**生成 5~10 条消息，随机分配到 **07:00~23:00** 之间的不重复时间点，由 AI 根据**人格设定**和每个时间点的场景撰写各不相同的内容，存入内部存储；**到点自动发送该条并删除**，第二天再生成新计划，日复一日。全程不向用户发送任何报备/确认消息。

> 灵感来源：机器人"突然冒出一句话"（如 QQ 官方适配器日志里的 `Agent 使用工具: ['send_message_to_user']`）——那是 AstrBot 的主动型 Agent/定时任务在主动聊天。本插件把这类行为统一收编：**只有本插件允许的人格消息能在用户没说话时发出去**。

## 🧩 工作原理

### 门禁（拦截层）

插件激活时，在 `Context.send_message`（AstrBot 唯一的**主动发送**入口）上安装一层拦截：

- 非本插件的主动发送 → **直接丢弃**，并在日志记录（`[proactive_guard] 已拦截非白名单主动消息 -> ...（来源模块: ...）`），不打扰用户；
- 以下情况放行：
  - **本插件自己**发送（每日人格消息，带内部标记）；
  - **白名单插件**（配置 `allow_senders`，如 `daily_digest`）；
  - **用户最近活跃的会话**（默认 30 分钟内用户发过消息 → 视为正常对话回复，可配 `active_window_minutes`）；
- 可选 `strict_mode`：只放行本插件，其余一律拦截。

同时插件会**自动暂停** AstrBot 内置的「主动型 Agent」定时任务（`cron_manager` 中的 `active_agent` 任务，**可逆**，不会删除；在面板可恢复）。用户正常消息的回复走的是另一条发送链路，**不受影响**。

### 每日计划（生成层）

1. 每天 `gen_time`（默认 06:00，cron 可配）触发；
2. 在 `window_start ~ window_end`（默认 07:00~23:00）内随机抽取 5~10 个**互不相同**的时间点（`msg_count_min/max` 可配）；
3. 调用 AstrBot 当前 LLM，按 `persona`（人格）和每个时间点的场景写一条消息，输出 JSON；
4. 存入插件 KV 存储（`daily_schedule`，含日期，重启不丢）；
5. 每**分钟**检查一次：到点 → 发送 → **删除该时间点**；错过未发（设备休眠）→ 30 分钟补偿窗口内补发，超窗丢弃；生成失败 → 每 20 分钟自动重试（06:00~11:00 窗口内）。

## 📦 安装

1. AstrBot WebUI →「插件」→「安装插件」→「通过 Git 地址安装」
2. 输入：`https://github.com/SeaSmall/astrbot-plugin-proactive-guard`
3. 启用插件，在配置面板按需修改（人格、时间窗口、目标会话等）

> 要求 **AstrBot 4.x**。

## ⚙️ 配置说明

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `enabled` | bool | `true` | 总开关 |
| `block_proactive` | bool | `true` | 门禁开关：拦截非本插件的 AI 主动发言 |
| `strict_mode` | bool | `false` | 严格模式：只放行本插件，连"用户最近活跃会话"也拦截 |
| `active_window_minutes` | int | `30` | 活跃窗口（分钟）：用户此窗口内发过消息的会话放行（视为正常对话） |
| `allow_senders` | text | 空 | 主动发送白名单：插件模块名关键词，每行一个（如 `daily_digest`） |
| `pause_active_agent_jobs` | bool | `true` | 启用时自动暂停 AstrBot 内置主动型 Agent 任务（可恢复） |
| `gen_time` | string | `0 6 * * *` | 每日生成计划时间（cron，默认每天 06:00） |
| `persona` | text | 见默认值 | 人格设定：AI 写消息时遵循的人设 |
| `message_prompt` | text | 见默认值 | 写消息提示词模板（`{persona} {date} {time_list} {count}` 自动替换） |
| `msg_count_min` / `msg_count_max` | int | `5` / `10` | 每日消息条数范围 |
| `window_start` / `window_end` | string | `07:00` / `23:00` | 消息时间窗口 |
| `missed_grace_minutes` | int | `30` | 错过补发窗口（分钟），超窗丢弃 |
| `target_sessions` | text | 空 | 发送目标会话（unified_msg_origin，每行一个）；留空自动选择 |
| `only_private` | bool | `true` | 未指定目标时：仅发私聊会话，不打扰群聊 |

## 🎮 指令（用户主动触发，可选）

| 指令 | 说明 |
| --- | --- |
| `/今日计划` | 查看今日待发送的人格消息计划 |
| `/重建今日计划` | 立即在后台重新生成今日计划（静默） |

## ❓ 常见问题

**Q：装上门禁后，之前的"突然冒话"还会出现吗？**
不会。主动型 Agent 任务会被自动暂停，且即使任何插件/AI 尝试主动发送，也会被门禁拦截（日志可见）。

**Q：会不会误伤正常聊天？**
不会。用户发消息→机器人回复走的是正常链路，不经过门禁；只有"用户没发消息时的主动发送"才被拦截。同一会话 30 分钟内有用户消息时，AI 的回复/发送也正常放行。

**Q：机器人错过到点的消息怎么办？**
30 分钟（`missed_grace_minutes`）内自动补发，超过则丢弃该条，不堆积。

**Q：想恢复 AstrBot 自带的主动型能力？**
在 AstrBot 面板恢复被暂停的主动任务，并关闭本插件的 `pause_active_agent_jobs` 或直接禁用本插件门禁（`block_proactive`）。
